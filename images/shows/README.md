# Show posters

Drop past-show flyer images here. `shows.html` expects:

- `kimbros-2026-08-08.png` — Live at Kimbro's, Aug 8 2026, Franklin TN
- `the-pond-2026-07-11.png` — Live at The Pond, Jul 11 2026, Franklin TN
  (transparent PNG — rendered with a faded pink/purple tint via the
  `.poster-tint-fade` CSS class in `css/style.css`, since the source
  art is black line-work on a transparent background)

Add more shows by copying a `.poster-card` block in `shows.html` and
dropping the new image in this folder.
